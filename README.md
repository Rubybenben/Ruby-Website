# Ruby Li Personal Website

A clean, professional single-page website for SAP Supply Chain Functional Consultant Ruby (Ting) Li.

## Updating Content

### 1. Text Updates
Edit `index.html` directly in any text editor. The file is structured with clear comments marking each section.

### 2. Photo Replacement
Replace `photo-placeholder.jpg` with your professional photo (recommended: 400x400px, JPEG format).

### 3. Style Customization
Edit `style.css` to modify colors, fonts, or layout. Color variables are defined at the top of the file.

### 4. No Build Process Required
Just edit the files and refresh your browser to see changes.

## File Structure
- `index.html` - Main content and structure
- `style.css` - All styling
- `script.js` - Interactive features
- `photo-placeholder.jpg` - Profile photo placeholder
